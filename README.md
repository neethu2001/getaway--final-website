# Getaway Beach Resort Kovalam

A modern, responsive website developed for **Getaway Beach Resort Kovalam**, designed to showcase the resort, accommodations, dining experiences, activities, events, and booking options in a premium and user-friendly interface.

## 🌴 Project Overview

The website provides visitors with an immersive digital experience to explore the resort and easily access important information. It includes dedicated accommodation pages, dining information, event enquiries, and direct room booking functionality.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Premium resort-inspired user interface
* Full-screen hero section with video background
* Resort overview and experience sections
* Dedicated accommodation section
* Individual pages for different room types
* Room details and booking options
* Coastal Flavour Restaurant section
* Restaurant menu and dining enquiry form
* Events section with enquiry functionality
* Direct room booking integration
* Contact and reservation information
* Smooth animations and transitions
* SEO-friendly page titles and metadata
* Mobile-friendly navigation

## 🏨 Accommodation

The accommodation section allows visitors to explore different room categories through dedicated pages.

Each room page provides:

* Room name
* Room description
* Room size
* Facilities and amenities
* Images
* Booking option

## 🍽️ Dining

The Dining page showcases the resort's **Coastal Flavour Restaurant** and provides access to the restaurant menu.

Guests can also submit dining enquiries through the website. Enquiries are forwarded to:

`reservations@getawaybeachresort.com`

## 🎉 Events

The Events section allows visitors to enquire about hosting events at the resort.

Submitted event enquiries are forwarded to the resort's reservation team for further assistance.

## 🔗 Booking

Visitors can book rooms through the integrated external booking system.

The website provides clear **Book Now** and room-specific booking options to make the reservation process simple and accessible.

## 📩 Enquiry Management

The website includes enquiry forms for dining and events. Submitted information is configured to reach the resort's designated reservation email.

For production deployment, the email/CRM integration should be tested to ensure enquiries are received correctly.

## 🌐 Deployment

The website can be deployed using platforms such as:

* GitHub Pages
* Netlify
* Vercel
* Traditional web hosting

Before deployment, ensure that all image paths, booking links, enquiry endpoints, and domain settings are correctly configured.
